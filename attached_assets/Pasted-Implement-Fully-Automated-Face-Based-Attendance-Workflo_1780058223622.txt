Implement Fully Automated Face-Based Attendance Workflow. Remove all manual attendance entry options from the Operator application. Attendance can only be marked after successful face recognition. The operator will open the Face Attendance screen, the camera will scan the worker's face, generate facial embeddings locally, compare them with the registered worker embeddings stored on the device, and if the match confidence is above the configured threshold (e.g., 95%), attendance is automatically marked. No manual worker selection or manual attendance buttons should be available.

Offline-First Architecture: The entire face recognition process must work without internet connectivity. When attendance is captured offline, save the record locally in SQLite with Worker ID, Worker Name, Operator ID, Toll Plaza ID, Device ID, Timestamp, Attendance Status, Face Match Score, and Sync Status = Pending. The operator should continue working normally even without network access.

Auto Sync Engine: The app must continuously monitor internet connectivity. When internet becomes available, automatically sync all pending attendance records from SQLite to the central database/server in the background without operator intervention. After successful upload, update Sync Status from Pending to Synced. If syncing fails, keep retrying automatically until successful.

Security Rules: Attendance can only be marked from the device allocated by Admin. Before every face scan, verify Device ID, Android ID/iOS Vendor ID, Device Token, Assigned Operator, and Assigned Toll Plaza. If the device is unauthorized, block attendance and show "Unauthorized Device".

Dashboard Analytics: Show Total Attendance Today, Pending Sync Records, Last Sync Time, Device Status, Offline Mode Status, and Face Recognition Success Rate. All statistics must be generated from actual SQLite data and synced records, not mock data.

No Manual Attendance Anywhere: Remove manual attendance forms, manual present/absent buttons, and manual worker selection screens. Attendance must only be generated through successful face recognition.
