Upgrade the existing Admin module by introducing a complete Device Registry and Device Allocation workflow. Do not allow the Admin to directly register workers or mark attendance. The Admin's responsibility is to manage Toll Plazas, Operators, Devices, Security, and Monitoring. First, create a Toll Plaza Management module where the Admin can register, edit, activate, or deactivate Toll Plazas. Next, create an Operator Management module where the Admin can create Operator accounts and assign each Operator to a specific Toll Plaza. Add a new Device Registry module where the Admin can register physical devices before allocation. Each device should contain Device Name, Device Model, Platform (Android/iOS), Device ID, App Generated Token, Registration Date, and Status (Available, Allocated, Blocked, Inactive). Create separate tabs for Available Devices, Allocated Devices, and Blocked Devices.

After a device is registered, provide a Device Allocation module where the Admin can assign a registered device to a specific Operator and Toll Plaza. The allocation screen should display Operator Name, Operator ID, Assigned Toll Plaza, Device Name, Device Model, Device ID, Allocation Date, and Status. The Admin should also be able to replace devices, deactivate devices, block devices, and reassign devices if a phone is lost, damaged, or replaced.

On the Operator side, when an Operator logs in, the system must automatically verify the current device against the assigned device stored in the allocation database. Attendance operations must only be allowed if the device matches the allocated device and the Operator belongs to the assigned Toll Plaza. If the device does not match, immediately block attendance operations and display an Unauthorized Device message. Every worker registered by the Operator must automatically inherit the Operator's Toll Plaza assignment. The Operator should not manually select a Toll Plaza during worker registration because it should already be linked through the assigned Operator and authorized device.

All worker registrations, face enrollments, attendance records, attendance history, and synchronization records must automatically store Toll Plaza ID, Operator ID, Device ID, Worker ID, Timestamp, and Sync Status. Every attendance transaction should be traceable to the exact Toll Plaza, Operator, and Device that performed the action. Add Admin dashboards for Toll Plaza Monitoring, Operator Monitoring, Device Monitoring, Unauthorized Device Attempts, Attendance Monitoring, Sync Status Monitoring, and Security Logs. The entire system should support offline-first operations, local storage, synchronization queues, audit logs, and enterprise-grade security. The final architecture should follow the flow: Admin registers Toll Plaza → Admin creates Operator → Admin registers Device → Admin allocates Device to Operator → Operator logs in from authorized device → Operator registers workers → Operator marks attendance → All records are automatically linked to the assigned Toll Plaza, Operator, and Device.
